# SarlaYash Blessings Internships 2026 — Batch 01

An immersive, self-contained cinematic welcome deck built with HTML, CSS, and vanilla JavaScript. No server, account, dependencies, or build step is needed.

## Run

Open `index.html` in a modern browser. For the cleanest live presentation, use the fullscreen button in the lower-right corner, or press `F`.

## Controls

| Control | Action |
| --- | --- |
| Right Arrow / Space | Next screen |
| Left Arrow | Previous screen |
| Esc | Screen overview |
| F | Fullscreen |
| P | Presenter mode (speaker notes, next screen, elapsed time) |
| M | Hidden Batch 01 Memory Wall |
| Bottom-left music control | Toggles the continuous peaceful ambient score |

The ten-second reflection on Screen 02 is intentionally not auto-advancing.

## Editing content

All presentation copy and speaker notes are in `index.html` and `script.js` respectively. The Memory Wall placeholders are at the end of `index.html`; edit those after the batch has milestones to preserve. Visual styling, motion, and responsiveness are in `style.css`.

The ambient score begins with the first navigation click or key press (a standard browser requirement), or immediately when the music control is selected. Animations honor the browser's reduced-motion preference.
