# SarlaYash Batch 01 — Personalized Onboarding

Open `index.html` in any modern browser. This is a standalone, no-server experience.

## Experience

- 10 premium black-and-gold onboarding steps
- Personal name entry and live India date/time
- One acknowledgement per onboarding standard
- Keyboard arrows / Space for navigation
- Completion summary downloaded as a personal `.txt` file
- Exit controls in the header and completion screen

Edit the step copy in `index.html`, visual design in `style.css`, and the personalized flow and summary format in `script.js`.
